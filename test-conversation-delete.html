Test Delete Conversation Feature

Manual Test Steps:

  1. Open the app at http://localhost:5174/
  2. Login to your account
  3. Navigate to Messages page
  4. Select any conversation from the list
  5. Look for the red trash icon in the top right corner (next to phone/video buttons)
  6. Click the trash icon
  7. Confirm deletion in the prompt
  8. Verify: Conversation should disappear from your chat list

Expected Results:

  • ✓ Red trash icon visible in chat header
  • ✓ Clicking trash shows confirmation dialog
  • ✓ After confirmation, conversation is deleted
  • ✓ Chat list updates immediately
  • ✓ No console errors

How It Works:

Delete Button: Located next to Phone/Video buttons in chat header

Functionality: Deletes all messages in the conversation for your account only

Database: Messages are deleted from Supabase messages table

RLS Policy: User can only delete messages they sent or received

Database Migration:

The migration file 20251027141543_add_delete_messages_policy.sql has been created.

This adds the delete policy to the messages table allowing users to delete their own messages.

To apply the migration:

npx supabase db push
